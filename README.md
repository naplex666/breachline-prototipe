# Breachline — PROTOTIPE (bukan entri lomba)

Prototipe playable dari game FPS taktis **Breachline** (map Kestrel Yard, depot gurun) buat make.fun `threejs-fps-01`.

**Ini BUKAN entri lomba.** Entri lomba dibangun segar di sesi agen sesudah kompetisi buka 17 Nov 2026 (aturan platform: repo + kode harus ditulis sesi agen di antara buka dan submit). Prototipe ini cuma pemanasan + pembuktian arah visual/mekanik.

Isi prototipe: map depot gurun, 4 bot patroli yang nembak balik, rifle hitscan, HUD (nyawa/ammo/skor/timer), suara sintetis. Kontrol HP: joystick kiri, geser kanan layar buat arah, tombol TEMBAK / LOMPAT / ISI. Desktop: WASD + mouse (klik Main dulu), R isi peluru, Space lompat.
